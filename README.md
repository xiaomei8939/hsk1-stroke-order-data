# HSK 1 Stroke-Order Data Subset

Character stroke-order data subset used to generate the printed stroke-order
diagrams in the book **Chino HSK 1: Vocabulario y escritura para
hispanohablantes** by Julian Cross (500 words, GF 0025-2021 Level 1).

## Source chain

- Original glyph/stroke data extracted from the PL fonts of **Arphic
  Technology Co., Ltd.**, released in 1999 under the **Arphic Public License**
  (see `ARPHICPL.TXT`, reproduced unaltered).
- Extracted and published by the **Make Me A Hanzi** project.
- Redistributed as **hanzi-writer-data** v2.0.1 (this subset is a verbatim
  copy of the per-character JSON files for the 300 unique characters used in
  the book).

## Modification notice (Arphic Public License §2a)

On 2026-11-22, the 300 character files in `data/` were selected as a subset
of hanzi-writer-data, and their stroke paths were converted in format
(rendered as step-by-step printed stroke-order diagrams) for inclusion in the
book named above. The data files themselves are unmodified verbatim copies.
The subset is made freely available as a whole under the same license, the
Arphic Public License, as required by §2b.
